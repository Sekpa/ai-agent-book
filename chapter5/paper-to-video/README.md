# 把逐页讲解与画面同步成视频

[本章实验目录](../README.md) · [相关正文](../../book/chapter5.md) · [技术参考](REFERENCE.md)

论文讲解视频需要把页面、口语化讲稿和音频放在同一条时间线上。本实验拆开这些环节，让你理解视频自动生成中内容组织与媒体处理各自承担什么工作。

## 理解实验

讲稿决定每页要说什么，TTS 决定音频，合成程序根据音频时长安排画面。若只给每页固定时长，讲解容易与页面错位；若机械照读页面，听众也可能难以理解。

## 动手之前

本节先使用本地示例或已有数据，不需要模型 API Key。安装依赖仍可能需要联网。 通用环境说明见[实验学习指南](../../docs/EXPERIMENTS.md)。

## 一步步观察

先检查本机的 ffmpeg、字体与配置，再用技术参考中的离线模式理解页面合成。离线音频是占位内容。接入真实生成后，先只处理第一页，听完并核对画面，再扩展到多页。

以下命令从本实验目录运行；请先完成上面的环境准备。

```bash
python demo.py --check
```

## 怎样解释结果

分别检查文字是否适合口头讲解、声音是否清晰、页面切换是否跟随讲解。文件时长正常不能证明同步正确，应在句子和页面边界实际播放检查。

## 继续思考

一页信息过多时，应让语速更快，还是拆分讲解与画面？怎样判断观众能否跟上？
