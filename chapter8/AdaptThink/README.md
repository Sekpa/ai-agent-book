# 学习何时值得投入更多推理

[本章实验目录](../README.md) · [相关正文](../../book/chapter8.md) · [技术参考](REFERENCE.md)

简单问题可能不需要很长的推理，而困难问题可能从额外计算中受益。本项目研究如何让模型根据任务选择推理方式，而不是对所有输入使用同样的过程。

## 理解实验

训练比较带推理与直接回答的样本，并在质量约束下调整行为。这里的关键是质量与计算投入之间的关系：回答更短可能更高效，也可能只是遗漏了必要步骤。

## 动手之前

训练需要独立的数据与计算环境。先按技术参考核对数据准备、模型版本与硬件要求；第一次练习只检查少量样本和一个短流程。 通用环境说明见[实验学习指南](../../docs/EXPERIMENTS.md)。

## 一步步观察

先阅读技术参考中两种响应模式与采样方法，挑选简单和困难问题分别检查基线。再准备外部训练源码，进行对照训练，并按难度划分留出任务。

## 怎样解释结果

同时观察正确率、选择推理的比例和生成长度。总体平均值可能掩盖困难问题退化，因此应分组分析，并将历史训练报告与自己运行的结果区分。

## 继续思考

如果模型减少了推理长度，却只在简单题上保持正确，能否说它学会了自适应推理？
