# 让语言控制与任务正确性分别可测

[本章实验目录](../README.md) · [相关正文](../../book/chapter8.md) · [技术参考](REFERENCE.md)

用户希望模型用某种语言解释思路，但语言符合要求并不意味着解题正确。本实验在多语言训练与评估中把语言控制和任务能力分开观察。

## 理解实验

训练样本包含语言条件与相应响应，模型学习在指定条件下生成。数据中各语言的数量、质量与题目难度都会影响结果，因此需要按语言分别评价。

## 动手之前

训练需要独立的数据与计算环境。先按技术参考核对数据准备、模型版本与硬件要求；第一次练习只检查少量样本和一个短流程。 通用环境说明见[实验学习指南](../../docs/EXPERIMENTS.md)。

## 一步步观察

先阅读训练脚本中样本转成消息的过程，确认语言条件实际进入输入。准备模型与数据后，进行短训练，再用相同难度的留出任务比较不同语言的表现。

## 怎样解释结果

检查回答是否使用指定语言、结论是否正确，以及是否混入其他语言。不要因表达更流畅就推断推理更强，也不要把某一语言上的结果推广到全部语言。

## 继续思考

如果一种语言的正确率较低，怎样区分数据不足、翻译错误与题目难度不一致？
