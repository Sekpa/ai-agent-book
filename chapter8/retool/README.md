# 在训练过程中学习何时调用代码工具

[本章实验目录](../README.md) · [相关正文](../../book/chapter8.md) · [技术参考](REFERENCE.md)

模型知道怎样写代码，不一定知道何时值得调用工具。本项目把代码执行纳入训练时的交互，让你理解工具反馈怎样进入学习过程。

## 理解实验

一次采样可以包含思考、代码、执行结果和后续回答。奖励需要评价任务结果，同时保留这些步骤的对应关系。执行服务与训练框架是两个组件，必须先确认它们能正确交换结果。

## 动手之前

训练需要独立的数据与计算环境。先按技术参考核对数据准备、模型版本与硬件要求；第一次练习只检查少量样本和一个短流程。 通用环境说明见[实验学习指南](../../docs/EXPERIMENTS.md)。

## 一步步观察

先阅读技术参考中的单条工具轨迹，指出哪些内容由模型产生、哪些来自执行器。准备 veRL 与执行服务后，先验证一条普通计算任务，再开始短训练。

## 怎样解释结果

工具调用次数增加不一定是进步。应检查正确率、计算成本、执行失败后的修正行为，以及模型是否在不需要工具时仍反复调用。

## 继续思考

一个错误程序产生了看似合理的结果，训练时怎样避免奖励误导后续策略？
