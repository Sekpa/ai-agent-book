# 用内部反馈训练时怎样避免自信替代正确

[本章实验目录](../README.md) · [相关正文](../../book/chapter8.md) · [技术参考](REFERENCE.md)

通常奖励来自答案校验或外部评价。Intuitor 探索使用模型自身分布中的确定性信号进行训练，适合学习内部反馈与任务正确性之间的区别。

## 理解实验

内部确定性描述模型对输出分布的状态，不是独立的事实验证。训练可以优化这个信号，但真正是否改善能力仍需要外部留出任务检查。应特别留意“更确定地答错”的可能性。

## 动手之前

训练需要独立的数据与计算环境。先按技术参考核对数据准备、模型版本与硬件要求；第一次练习只检查少量样本和一个短流程。 通用环境说明见[实验学习指南](../../docs/EXPERIMENTS.md)。

## 一步步观察

先读技术参考中的奖励计算，找出它使用的模型输出信息。准备外部训练环境前，先分析已有输出与正确答案之间的关系，再进行短训练和独立评估。

## 怎样解释结果

内部奖励上升不等于正确率上升。比较不同题型、正确与错误样本的分布，并检查输出是否变得单一或失去必要探索。

## 继续思考

若内部信号与正确性只在部分题型相关，训练和评价应怎样反映这种适用范围？
