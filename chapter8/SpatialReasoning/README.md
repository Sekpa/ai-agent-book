# 比较不同训练方法的跨环境表现

[本章实验目录](../README.md) · [相关正文](../../book/chapter8.md) · [技术参考](REFERENCE.md)

导航策略在熟悉街景中表现好，未必能适应另一座城市。本实验围绕 V-IRL 任务比较 SFT 与 RL，学习怎样设计分布内外的泛化测试。

## 理解实验

SFT 学习示范动作，RL 根据交互结果调整策略。训练方式不同，但公平比较仍需控制基础模型、任务与评估条件。新规则与新视觉环境是不同变化，应分别测试。

## 动手之前

训练需要独立的数据与计算环境。先按技术参考核对数据准备、模型版本与硬件要求；第一次练习只检查少量样本和一个短流程。 通用环境说明见[实验学习指南](../../docs/EXPERIMENTS.md)。

## 一步步观察

先阅读任务中的观察、动作和成功条件，再按技术参考取得 SFTvsRL 源码与环境。选择一条示范轨迹理解监督目标，随后比较两种方法在熟悉场景和未见场景的行为。

## 怎样解释结果

不能先把 SFT 定义为记忆、把 RL 定义为泛化。结论应来自具体数据划分与结果，还要检查训练预算、样例覆盖和环境变化是否一致。

## 继续思考

如果只换城市就退化，怎样判断问题来自视觉识别还是导航规则理解？
