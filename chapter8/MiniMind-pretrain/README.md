# 从小模型理解预训练与后训练的分工

[本章实验目录](../README.md) · [相关正文](../../book/chapter8.md) · [技术参考](REFERENCE.md)

把模型规模缩小后，更容易完整观察数据如何进入训练、损失怎样计算、不同训练阶段怎样改变输出。本项目以 MiniMind 及其视觉扩展为线索，串起这些概念。

## 理解实验

预训练学习文本分布，监督微调学习示范中的响应方式，偏好训练进一步改变候选响应之间的倾向。视觉扩展还需要把图像信息接到语言处理路径。阶段之间有联系，但各自的数据与目标不同。

## 动手之前

训练需要独立的数据与计算环境。先按技术参考核对数据准备、模型版本与硬件要求；第一次练习只检查少量样本和一个短流程。 通用环境说明见[实验学习指南](../../docs/EXPERIMENTS.md)。

## 一步步观察

先在技术参考中选择纯文本或视觉路线，并取得对应外部源码。阅读一条训练样本和损失计算，进行短流程检查后，再运行训练。保存各阶段相同问题的输出，逐项比较变化。

## 怎样解释结果

损失下降只说明对所用目标的拟合改善。生成样例应来自未用于训练的问题，还应保留表现变差的案例。历史报告与已发布检查点的可用性需要分别确认。

## 继续思考

如果模型更会遵循格式，却在事实问题上没有进步，哪一个训练目标可能得到改善？
